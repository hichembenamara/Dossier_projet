Lecture des cardinalités : le libellé donne les cardinalités Merise (min,max) dans le sens entité de gauche → entité de droite, puis l'inverse quand il n'est pas (1,1). Identifiants : les attributs marqués PK sont les identifiants conceptuels ; les clés techniques auto-incrémentées apparaissent seulement dans le MPD. SEANCE_EXERCICE est une association porteuse entre séance et exercice, matérialisée en table dans le MPD.
